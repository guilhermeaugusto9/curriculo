# Guilherme Augusto — Portfólio

Engenheiro de Dados e Professor de Dados e IA. Site estático (HTML, CSS e JavaScript), bilíngue (PT/EN), sem build e sem dependências. Publicado via GitHub Pages: https://guilhermeaugusto9.github.io/curriculo/

## Estrutura

- `index.html` — estrutura, metadados e JSON-LD
- `styles.css` — tema preto e laranja (tokens em `:root`)
- `app.js` — todo o conteúdo em PT e EN
- `assets/` — foto e dino

## Editar

Os textos ficam em `app.js` (objetos `pt` e `en`). Para pré-visualizar: `python3 -m http.server 8000` e abrir `http://localhost:8000`.

Os arquivos antigos do tema Bootstrap (`css/`, `js/`, `scss/`, `vendor/`, `img/`, `gulpfile.js`) não são mais usados pelo site.
